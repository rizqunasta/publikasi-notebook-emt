# Publikasi Notebook Euler Math Toolbox

## Deskripsi

Repositori ini berisi kumpulan notebook Euler Math Toolbox (EMT) untuk pembelajaran dan dokumentasi matematika. Setiap materi disediakan dalam format notebook asli, Markdown, LaTeX, dan PDF.

## Struktur Proyek

- `Notebook/` — Notebook asli EMT (`.en`).
- `Images/` — Kumpulan gambar pendukung.
- `Markdown/` — Hasil ekspor Markdown (`.md`).
- `LaTeX/` — Berkas sumber LaTeX (`.tex`).
- `PDF/` — Dokumen PDF hasil kompilasi.
- `Dokumentasi/` — Dokumentasi tambahan proyek.
